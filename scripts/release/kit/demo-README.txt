1. "Malkkeum Demo.cmd" 더블클릭: 서버, 예시 데이터, 관리자 콘솔(http://localhost:8081), 에뮬레이터 앱 실행 / Double-click: server, sample data, owner console, emulator apps.
2. 콘솔 로그인 owner@demo.local / malkkeum-demo-2026. 앱 로그인은 아무 번호, 6자리 인증번호가 화면에 표시 (SMS 없음) / Any phone number; the 6-digit code is shown on screen.
3. 실제 휴대폰: 같은 Wi-Fi, Malkkeum-Customer.apk / Malkkeum-Partner.apk 설치 (주소는 api-address.txt) / Real phone: same Wi-Fi, install the APKs (address in api-address.txt).
4. 필요: Windows 10/11, Postgres 17 (포트 5433, bin 폴더가 PATH 또는 PG_BIN 에, 꺼져 있으면 PGDATA 필요), Android SDK; 방화벽은 "개인 네트워크" 허용 / Needs Windows 10/11, Postgres 17 on port 5433 (bin folder on PATH or in PG_BIN; PGDATA if it is not running yet), Android SDK; allow api.exe on Private networks.
5. 서버 창 "Malkkeum Server" 를 체험 중에는 닫지 마세요 / Keep the "Malkkeum Server" window open during the demo.
