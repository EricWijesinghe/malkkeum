다해 관리자 (Dahae Console) 안드로이드 앱 설치 안내
====================================================

이 앱은 구글 플레이 같은 스토어에 올리지 않아요. 파일(Dahae-Console.apk)을 폰으로 옮겨서 직접 설치해요.
(웹에서는 https://내도메인/admin/ 으로 그대로 쓸 수 있어요.)

1. Dahae-Console.apk 를 폰으로 보내세요 (카카오톡 "나와의 채팅", 이메일, USB, 구글 드라이브 등).
2. 폰에서 파일을 열면 "출처를 알 수 없는 앱" 설치 허용 안내가 나와요.
   설정 > 허용 (이 앱/브라우저/파일 앱에 대해서만 켜면 돼요). 설치가 끝나면 다시 끄셔도 돼요.
3. 설치를 누르세요. 구글 Play Protect 가 "확인되지 않은 앱" 이라고 물으면 "그래도 설치" 를 누르세요.
4. "다해 관리자" 앱을 여세요. 처음 한 번 서버 주소를 물어봐요.
   설치할 때 안내받은 https:// 로 시작하는 주소 (예: https://내도메인) 를 입력하고 "저장하고 계속" 을 누르세요.
   https 가 아닌 주소는 받지 않아요.
5. 관리자 이메일과 비밀번호로 로그인하세요 (2단계 인증을 켰다면 인증 앱 코드도 필요해요).

주소를 잘못 넣었거나 서버를 옮긴 경우: 로그아웃 상태의 로그인 화면 맨 아래 "서버 주소 변경" 을 누르세요.

업데이트: 새 Dahae-Console.apk 를 같은 방법으로 설치하면 기존 위에 덮어써요 (로그인과 서버 주소는 유지돼요).
같은 서명 키로 만든 파일만 덮어쓸 수 있어요. 서명 키(3-Store-Android/signing)를 잘 보관하세요.

Dahae Console for Android: install guide

Not on any store: copy Dahae-Console.apk to the phone and install it yourself.
1. Send the APK to the phone (chat to yourself, email, USB, Drive).
2. Open it and allow "install unknown apps" for that app only (Settings > Allow). Turn it off again afterwards if you like.
3. Tap Install. If Google Play Protect warns about an unrecognised app, choose "Install anyway".
4. Open "다해 관리자". On first launch enter the server address (https:// only), then "저장하고 계속" (Save and continue).
5. Sign in with the admin email and password (plus the authenticator code if two-step sign-in is on).
Wrong address: on the sign-in screen tap "서버 주소 변경" (Change server address).
Updates install over the old app if the new APK is signed with the same key.
