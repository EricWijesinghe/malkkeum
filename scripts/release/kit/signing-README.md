# 업로드 키 · Upload keystore (DO NOT SHARE / 공유 금지)

**파일 / Files**
- `malkkeum-upload.p12`: 업로드 키 저장소 (PKCS12). Alias `upload`.
- `PASSWORD.txt`: 저장소 비밀번호 = 키 비밀번호 (store and key password are the same).

**이것은 "업로드 키" 입니다 (Play App Signing).** 구글 플레이가 실제 배포 서명을 따로 보관해요.
이 키를 잃으면 Play Console 의 앱 서명 키 재설정 (지원팀) 으로 새 업로드 키를 등록할 수 있어요.
This is the **upload key** for Play App Signing. Google keeps the app-signing key. If this key is lost, reset it through Play Console support.

**백업 규칙 / Backup rules**
1. `malkkeum-upload.p12` 와 `PASSWORD.txt` 를 함께 두 곳 이상 (USB, 암호 관리자) 에 보관하세요.
2. 이 폴더 어디에도 git 커밋, 메일 첨부, 클라우드 공유를 하지 마세요.
3. 빌드 스크립트는 키를 파일로 쓰지 않고 환경 변수 (`CM_KEYSTORE_PATH`, `CM_KEYSTORE_PASSWORD`, `CM_KEY_ALIAS`, `CM_KEY_PASSWORD`) 로만 Gradle 에 넘겨요. `android/key.properties` 는 만들지 않아요.

**원본 위치 / Master copy:** 빌드 스크립트의 원본은 저장소 밖 `F:\EC\targets\release-keys\` 에 있어요. 다시 빌드해도 같은 키를 재사용하므로 새 키가 생기지 않아요. 이 폴더의 파일은 그 복사본이에요.
The build keeps the master copy outside the repo and reuses it on every run, so no new key is ever generated by accident.
