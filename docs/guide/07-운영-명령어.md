# 7. 운영 명령어 (`dahae`)

서버를 관리할 때 쓰는 명령이에요. 설치하면 자동으로 들어 있어요.

## 쓰는 방법
1. 서버 회사 화면에서 **"브라우저에서 SSH 연결"** 을 눌러 검은 화면을 열어요.
2. 아래 명령을 입력하고 Enter 를 눌러요.
3. 명령 앞에는 항상 `sudo` 를 붙여요 (관리자 권한이 필요해요).

전체 목록은 `sudo dahae help` 로 볼 수 있어요. 예전 이름 `malkkeum` 으로 입력해도 똑같이 돼요.

| 하고 싶은 일 | 명령 |
|---|---|
| 서버가 정상인지 보기 | `sudo dahae status` |
| 오류 기록 보기 | `sudo dahae logs` |
| 지금 백업하기 | `sudo dahae backup` |
| 백업으로 되돌리기 | `sudo dahae restore 파일` |
| 지금 업데이트하기 | `sudo dahae update` |
| 업데이트 전 버전으로 되돌리기 | `sudo dahae rollback` |
| 안정/베타 버전 바꾸기 | `sudo dahae channel stable` |
| 서버가 꺼지면 알림 받기 | `sudo dahae heartbeat 주소` |
| 앱 링크 연결 (개발자 요청 시) | `sudo dahae applinks …` |
| 서비스 제거 | `sudo dahae uninstall` |

---

## 1. status — 서버가 정상인지 보기
**언제:** 사이트가 안 열릴 때, 설치 직후, 그냥 궁금할 때.
```
sudo dahae status
```
- `✔ 앱 정상` — 서비스가 잘 돌고 있어요.
- `✔ HTTPS 정상: https://도메인/admin/` — 보안 인증서도 정상이에요.
- `! HTTPS 인증서가 아직 없어요` — 도메인의 A 레코드가 이 서버를 가리키는지 확인하세요. 맞으면 몇 분 안에 자동으로 발급돼요.
- `! 외부 가동 확인이 없어요` — 아래 8번(heartbeat)을 설정하세요.

[화면: `dahae status` 결과에 초록색 ✔ 세 줄이 보이는 모습]

## 2. logs — 오류 기록 보기
**언제:** `status` 에서 "앱 응답 없음" 이 나올 때, 개발자가 기록을 보내 달라고 할 때.
```
sudo dahae logs
```
- 최근 200줄을 보여 주고, 새 기록이 계속 이어져요. **Ctrl + C** 로 나가요.
- 화면을 캡처해서 개발자에게 보내세요.
- 웹 서버나 데이터베이스 기록은 `sudo dahae logs web`, `sudo dahae logs db`.

## 3. backup — 지금 바로 백업하기
**언제:** 큰 변경(가격표 대량 수정 등)을 하기 전에. 평소에는 매일 새벽 3시 30분에 자동으로 해요.
```
sudo dahae backup
```
- 끝나면 `✔ 백업 완료: /opt/malkkeum/backups/db-날짜-시각.sql.gz` 가 나와요.
- 고객·예약 데이터(`db-….sql.gz`)와 사진 파일(`uploads-….tar.gz`)을 함께 저장해요.
- 서버 안 백업은 14일 동안 보관해요.
- 콘솔 [설정] → [외부 백업]을 연결해 두면 서버 밖에도 한 부 올려요.
- 백업 목록 보기: `sudo ls /opt/malkkeum/backups`

## 4. restore — 백업으로 되돌리기
**언제:** 데이터를 실수로 지웠거나 망가졌을 때. **지금 데이터가 백업 시점으로 돌아가니** 꼭 필요할 때만 쓰세요.
```
sudo ls /opt/malkkeum/backups
sudo dahae restore backups/db-20261110-033000.sql.gz
```
1. 첫 줄로 백업 목록을 보고, 되돌릴 날짜의 `db-….sql.gz` 파일을 골라요.
2. 둘째 줄을 실행하면 "현재 데이터를 … 로 되돌릴까요?" 라고 물어요. `yes` 를 입력해요.
3. 되돌리기 전에 **지금 상태를 먼저 백업**해 둬요. 마음이 바뀌면 그 파일로 다시 되돌릴 수 있어요.
4. 같은 시각의 사진 파일 백업이 있으면 사진도 함께 되돌려요.
5. `✔ 복원 완료` 가 나오면 끝이에요.

- 중간에 오류가 나면 데이터는 바뀌지 않고 원래대로 남아요.
- 질문 없이 바로 실행하려면 끝에 `--yes` 를 붙여요: `sudo dahae restore backups/db-20261110-033000.sql.gz --yes`
- 서버가 통째로 고장 났을 때는 외부 백업에서 가져와요: `sudo dahae restore-offsite` (목록 보기) → `sudo dahae restore-offsite 이름`. [2. 설정 마법사](02-설정-마법사.md) 6번을 보세요.

## 5. update — 지금 업데이트하기
**언제:** 개발자가 "새 버전을 올렸어요" 라고 했는데 월요일까지 기다리기 싫을 때. 평소에는 매주 월요일 새벽 4시에 자동으로 해요.
```
sudo dahae update
```
- 순서: **백업 → 새 버전 받기 → 응답 확인**.
- `✔ 최신 버전(…)으로 업데이트했어요` 가 나오면 성공이에요.
- 새 버전이 3분 안에 응답하지 않으면 **자동으로 이전 버전으로 되돌려요.** 이때는 `sudo dahae logs` 화면을 개발자에게 보내 주세요.
- 지금 버전 확인: `sudo dahae version`

## 6. rollback — 업데이트 전 버전으로 되돌리기
**언제:** 업데이트는 성공했는데 화면이나 기능이 이상할 때.
```
sudo dahae rollback
```
- 바로 전 버전의 **프로그램**으로 돌아가요. 되돌리기 전에 백업도 해요.
- 고객·예약 같은 **데이터는 지우지 않아요.** 업데이트 뒤에 들어온 예약도 그대로 남아요.
- 프로그램만 되돌리고, 업데이트가 바꾼 데이터 저장 구조는 그대로 둬요. 데이터까지 예전 시점으로 돌리려면 4번(restore)을 쓰세요.
- 업데이트를 한 번도 하지 않았다면 "되돌릴 이전 버전 기록이 없어요" 라고 나와요.
- 되돌린 뒤에는 개발자에게 알려 주세요. 다음 월요일 자동 업데이트 때 다시 새 버전이 설치돼요.

## 7. channel — 안정/베타 버전 바꾸기
**언제:** 개발자가 "베타로 먼저 확인해 주세요" 라고 할 때만. 손님을 받는 서버는 `stable` 로 두세요.
```
sudo dahae channel beta
sudo dahae channel stable
```
- `stable` = 안정 버전 (기본값), `beta` = 먼저 써 보는 버전.
- 바꾸면 바로 그 채널의 버전으로 업데이트해요 (5번과 같은 순서).

## 8. heartbeat — 서버가 꺼지면 알림 받기
**언제:** 설치하고 한 번만. 서버는 자기가 꺼진 것을 스스로 알릴 수 없어서, 바깥 서비스가 지켜보게 해요.
1. healthchecks.io 같은 가동 확인 서비스에 가입하고 **체크(Check)** 를 하나 만들어요. 주기(Period) 5분, 유예(Grace) 15분.
2. 화면에 나오는 **핑 주소**(`https://hc-ping.com/…`)를 복사해요.
3. 검은 화면에 입력해요.
   ```
   sudo dahae heartbeat https://hc-ping.com/여기에-복사한-주소
   ```
4. `✔ 외부 가동 확인을 켰어요. 테스트 핑을 보냈어요.` 가 나오면 끝이에요.

- 서버가 5분마다 "잘 돌고 있어요" 신호를 보내요. 신호가 끊기면 그 서비스가 이메일 등으로 알려 줘요.
- 주소는 `https://` 로 시작해야 해요.
- 끄려면: `sudo dahae heartbeat off`

[화면: 가동 확인 서비스에서 핑 주소를 복사하는 모습]

## 9. applinks — 앱 링크 연결
**언제:** 앱을 스토어에 올릴 때, **개발자가 값을 알려 주면** 한 번만. 네이버 로그인이 앱으로 바로 돌아오게 해 줘요.
```
sudo dahae applinks --android-sha256 AA:BB:…(개발자가 준 값) --apple-team-id ABCDE12345
```
- 두 값 모두 개발자가 알려 줘요. 받은 그대로 붙여넣으세요.
- Android 지문이 여러 개면 쉼표로 이어 써요. 둘 중 하나만 먼저 넣어도 돼요.
- `✔ 앱 링크를 설정했어요` 가 나오면 끝이에요.

## 10. uninstall — 서비스 제거
**언제:** 서비스를 그만두거나 서버를 옮길 때. 먼저 `sudo dahae backup` 을 하고 백업 파일과 `.env` 파일을 다른 곳에 복사해 두세요.

**끄기만 하기 (데이터는 남김)**
```
sudo dahae uninstall
```
- `yes` 를 입력하면 서비스를 끄고 자동 백업·업데이트 예약과 `dahae` 명령을 지워요.
- 데이터와 백업은 서버에 그대로 남아요. 설치 명령을 다시 실행하면 이어서 쓸 수 있어요.

**전부 지우기 (되돌릴 수 없음)**
```
sudo dahae uninstall --purge
```
- 확인을 위해 **도메인을 직접 입력**해야 해요. `--yes` 로는 넘어가지 않아요 (스크립트에서는 `--confirm 도메인`).
- 고객·예약 데이터, 사진, 서버 안 백업, 보안 키까지 모두 지워요. **되돌릴 수 없어요.**
- 서버 임대와 도메인은 따로 해지해야 요금이 멈춰요.

## 그 밖의 명령
| 명령 | 하는 일 |
|---|---|
| `sudo dahae version` | 지금 채널과 버전 |
| `sudo dahae setup-code` | 사장님 계정을 만들 때 쓰는 설치 코드 다시 보기 |
| `sudo dahae restore-offsite` | 외부 백업 목록 / 내려받아 되돌리기 |
| `sudo dahae demo load` / `demo clear` | 체험용 데이터 넣기 / 지우기 ([1. 서버 설치](01-서버-설치.md)) |
| `sudo dahae load 파일.tar` | 인터넷 없이 업데이트할 때 이미지 파일 불러오기 ([5. 체험용 설치](05-demo-install.md)) |
