# 사장님 가이드 — 콘솔 하루 사용법

콘솔 주소: `https://도메인/admin/` — 따로 설치할 프로그램 없이 PC·휴대폰 모두 앱처럼 쓸 수 있어요.

## 앱처럼 설치하기 (한 번만)
| 기기 | 방법 |
|---|---|
| PC (Windows) | **Edge** 또는 **Chrome** 으로 콘솔 주소 열기 → 주소창 오른쪽 **앱 설치** 아이콘(⊕) → [설치]. 시작 메뉴·작업 표시줄에 "다해 관리자" 아이콘이 생겨요 |
| 안드로이드 폰 | **Chrome** 으로 콘솔 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** (또는 홈 화면에 추가). 홈 화면 아이콘으로 바로 열려요 |
| 아이폰 | **Safari** 로 열기 → 공유 버튼 → **홈 화면에 추가** |

새 기능은 업데이트할 필요 없이 다음에 열 때 자동으로 반영돼요.
`Ctrl + K` 를 누르면 메뉴나 예약번호를 바로 찾을 수 있어요.

## 매일 아침 5분
1. **대시보드**: 오늘 작업, 견적 대기, 미배정, 안 읽은 상담 숫자 확인
2. **미배정**이 있으면 [예약]에서 열어 파트너에게 연락하거나 일정 조정
3. **안 읽은 상담**은 [상담함]에서 답장 (고객 앱에 바로 알림이 가요)

## 시스템 상태 (매주 한 번, 문제 있을 때)
[시스템 상태]에서 서버가 건강한지 한눈에 봐요. 항목마다 **초록(정상) · 노랑(확인 필요) · 빨강(조치 필요)** 으로 표시돼요.

- **서버 상태**: 맨 위 색이 가장 나쁜 항목을 따라가요.
- **데이터베이스**: 응답 속도와 용량. 빨강이면 서버 재시작이나 설치 담당자 확인.
- **서버 디스크**: 여유 공간이 10% 아래면 빨강. 오래된 백업을 정리하거나 디스크를 늘려 주세요.
- **자동 백업**: 마지막 백업이 36시간 넘게 없으면 빨강. 설치 담당자에게 `sudo dahae backup` 확인을 요청하세요.
- **서버 오류 (24시간)**: 500번대 오류 건수. 많으면 노랑·빨강. 설치 담당자가 `sudo dahae logs` 를 보고 개발사에 전달해요.
- **결제 확인 필요**: 결제는 됐지만 자동 처리가 실패한 건이 있다는 뜻이에요. PortOne 관리자 화면에서 해당 결제를 확인하고 필요하면 직접 환불하세요.
- **결제 알림 (웹훅)**: 결제사 알림의 서명 검사가 실패했다는 뜻이에요. 설정 > 결제의 웹훅 시크릿을 다시 확인하세요.
- **외부 서비스**: 결제·문자·푸시·소셜 로그인마다 마지막 성공과 실패 시각, 오류 코드를 보여요. 빨강 항목 아래의 안내대로 설정 카드에서 키를 다시 붙여넣고 [연결 테스트] 를 누르세요.

**자동 알림**: 문제가 반복되면 상담함에 알림이 쌓이고, 사장님 휴대폰으로 문자가 가요. 같은 문제는 6시간에 한 번만 보내요. [시스템 상태] 맨 아래 **알림 설정**에서 어떤 알림을 받을지, 조용한 시간(기본 밤 10시 ~ 아침 7시), 문자 받을 번호를 정할 수 있어요. 조용한 시간에 생긴 문제는 시간이 끝난 뒤 한 번 알려 드려요.

## 견적 (이사·입주 청소)
1. [견적 데스크]에 새 요청이 쌓여요. 파트너들이 낸 견적이 함께 보여요.
2. 마음에 드는 파트너 견적을 고르고 최종 금액을 입력 → [견적 보내기]
3. 고객이 예약금(10%)을 결제하면 그 파트너에게 자동 배정돼요.

## 파트너 관리
- [파트너]: 새로 가입한 파트너를 확인하고 **[승인]**. 문제가 있으면 [정지].
- [정산]: 매주 수요일 지급 예정 목록. [지급 요청]을 누르면 지급 건이 만들어져요. 직접 이체 방식이면 [계좌 보기] 로 정보를 확인해 이체하고 [이체 완료로 표시]. 토스 지급대행이면 [토스로 지급 요청] → [상태 확인]. 실패한 건은 [다시 시도]. 분쟁이 있는 건은 [보류] (지급 요청된 건은 보류할 수 없어요).

## 마케팅
- [쿠폰 · 콘텐츠]: 홈 배너, 공지, 자주 묻는 질문을 한국어·영어로 편집. 고객에게 쿠폰 발급.
- [카탈로그 · 가격]: 서비스 가격, 시간대별 예약 가능 수, 이사 견적 공식 수정. 저장하면 앱과 웹사이트 가격이 바로 바뀌어요.

## 운영 규칙 (사장님이 정하는 한도)
- 메뉴 **운영 규칙**에서 사업장 한도, 광고 발송 횟수, 포인트 한도, 파트너 품질 기간, 서버·알림 기준을 바꿀 수 있어요.
- 각 항목 아래에 **입력 가능 범위**와 **바로 적용** 또는 **서버를 다시 시작해야 적용**이 적혀 있어요. 값을 바꾼 뒤 [저장]을 누르세요.
- 광고 발송 횟수, 포인트 한도, 서버 알림 기준은 **기본값보다 낮게만** (또는 알림 기준은 **더 빨리 알리도록만**) 바꿀 수 있어요. 후기 신고 기준은 **기본값보다 높게만** 바꿀 수 있어요. 안전을 위한 제한이에요.
- **기본값으로**를 누르면 설치 때의 값으로 돌아가요. 바꾼 내역은 서버 기록에 남아요.
- "여기서는 바꿀 수 없어요"라고 표시된 항목(예: 결제 대사 주기)은 개발자에게 문의하세요.

## 직원
- [직원]에서 상담 직원 계정을 만들 수 있어요. **상담원** 권한은 예약·상담만, **관리자**는 모든 설정까지.

## 이럴 땐 이렇게
| 상황 | 할 일 |
|---|---|
| 고객이 결제했는데 예약이 안 보인다고 함 | 1~2분 기다리면 자동 복구돼요 (결제사와 자동 대조). 그래도 없으면 [예약] 검색에 전화번호 입력 |
| 결제가 안 된다는 문의가 많음 | [설정] → 결제 카드의 [연결 테스트] |
| 인증 문자가 안 온다는 문의 | [설정] → 문자 카드의 [연결 테스트], Solapi 잔액 확인 |
| 설정 카드가 빨간색 | 카드 안 안내대로 키를 다시 붙여넣고 저장 |
| 서버가 안 열림 | 설치 담당자에게 `sudo dahae status` 확인 요청 |
