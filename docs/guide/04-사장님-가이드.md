# 사장님 가이드 — 콘솔 하루 사용법

콘솔 주소: `https://도메인/admin/` — 따로 설치할 프로그램 없이 PC·휴대폰 모두 앱처럼 쓸 수 있어요.

## 앱처럼 설치하기 (한 번만)
| 기기 | 방법 |
|---|---|
| PC (Windows) | **Edge** 또는 **Chrome** 으로 콘솔 주소 열기 → 주소창 오른쪽 **앱 설치** 아이콘(⊕) → [설치]. 시작 메뉴·작업 표시줄에 "말끔 관리자" 아이콘이 생겨요 |
| 안드로이드 폰 | **Chrome** 으로 콘솔 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** (또는 홈 화면에 추가). 홈 화면 아이콘으로 바로 열려요 |
| 아이폰 | **Safari** 로 열기 → 공유 버튼 → **홈 화면에 추가** |

새 기능은 업데이트할 필요 없이 다음에 열 때 자동으로 반영돼요.
`Ctrl + K` 를 누르면 메뉴나 예약번호를 바로 찾을 수 있어요.

## 매일 아침 5분
1. **대시보드**: 오늘 작업, 견적 대기, 미배정, 안 읽은 상담 숫자 확인
2. **미배정**이 있으면 [예약]에서 열어 파트너에게 연락하거나 일정 조정
3. **안 읽은 상담**은 [상담함]에서 답장 (고객 앱에 바로 알림이 가요)

## 견적 (이사·입주 청소)
1. [견적 데스크]에 새 요청이 쌓여요. 파트너들이 낸 견적이 함께 보여요.
2. 마음에 드는 파트너 견적을 고르고 최종 금액을 입력 → [견적 보내기]
3. 고객이 예약금(10%)을 결제하면 그 파트너에게 자동 배정돼요.

## 파트너 관리
- [파트너]: 새로 가입한 파트너를 확인하고 **[승인]**. 문제가 있으면 [정지].
- [정산]: 매주 수요일 지급 예정 목록. [지급 실행]을 누르면 지급 완료 처리. 분쟁이 있는 건은 [보류].

## 마케팅
- [쿠폰 · 콘텐츠]: 홈 배너, 공지, 자주 묻는 질문을 14개 언어로 편집. 고객에게 쿠폰 발급.
- [카탈로그 · 가격]: 서비스 가격, 시간대별 예약 가능 수, 이사 견적 공식 수정. 저장하면 앱과 웹사이트 가격이 바로 바뀌어요.

## 직원
- [직원]에서 상담 직원 계정을 만들 수 있어요. **상담원** 권한은 예약·상담만, **관리자**는 모든 설정까지.

## 이럴 땐 이렇게
| 상황 | 할 일 |
|---|---|
| 고객이 결제했는데 예약이 안 보인다고 함 | 1~2분 기다리면 자동 복구돼요 (결제사와 자동 대조). 그래도 없으면 [예약] 검색에 전화번호 입력 |
| 결제가 안 된다는 문의가 많음 | [설정] → 결제 카드의 [연결 테스트] |
| 인증 문자가 안 온다는 문의 | [설정] → 문자 카드의 [연결 테스트], Solapi 잔액 확인 |
| 설정 카드가 빨간색 | 카드 안 안내대로 키를 다시 붙여넣고 저장 |
| 서버가 안 열림 | 설치 담당자에게 `malkkeum status` 확인 요청 |
