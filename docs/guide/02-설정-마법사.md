# 2. 설정 마법사 (콘솔 → [설정])

모든 연동 키는 콘솔 화면에 붙여넣기만 하면 돼요. 저장하면 **암호화되어 보관**되고, 서버를 다시 켤 필요 없이 바로 적용돼요.
각 카드 안에 단계별 설명과 **[사이트 열기]** 버튼이 있어요. 저장하면 자동으로 **[연결 테스트]** 가 실행되고 초록색 "연결됨"이 나오면 성공이에요.

## 권장 순서와 준비물
| 순서 | 카드 | 필요한 것 | 걸리는 시간 |
|---|---|---|---|
| 1 | 사업장 정보 | 사업자등록증, 통신판매업 신고증, 로고 이미지 | 10분 |
| 2 | 결제 (PortOne) | 사업자등록, PortOne 가입과 PG사 심사 | 심사 3~10일 |
| 3 | 문자 · 알림톡 (Solapi) | 발신번호 등록 서류 | 1~2일 |
| 4 | 앱 푸시 (Firebase) | 구글 계정 | 10분 |
| 5 | 카카오 / 네이버 / 구글 / 애플 로그인 | 각 개발자 계정 | 각 10~20분 |

> 결제 심사를 기다리는 동안에도 다른 카드는 먼저 진행할 수 있어요.

## 1. 사업장 정보
- **서비스 이름·대표 색상·로고**: 앱 머리말, 웹사이트, 알림에 표시돼요. 색을 누르면 위쪽 미리보기가 바로 바뀌어요.
- **사업자 정보**: 법에 따라 웹사이트 하단과 약관에 표시해야 하는 정보예요. 입력하면 웹사이트에 자동으로 나타나요.
- **앱 스토어 주소**: 앱이 출시된 뒤 스토어 주소를 넣으면 웹사이트의 다운로드 버튼이 켜져요.

## 2. 결제 (PortOne)
카드 안의 6단계를 따라 하세요. 핵심만 요약하면:
1. admin.portone.io 가입 → 상점 아이디(Store ID) 복사
2. V2 API Secret 발급 → 복사
3. 채널 관리에서 결제수단(카드·카카오페이·네이버페이·토스페이…)마다 채널 추가 → 채널 키를 같은 이름 칸에
4. 웹훅: 카드에 보이는 **웹훅 주소**를 복사해 PortOne에 붙여넣고(V2), 나온 `whsec_…` 시크릿을 붙여넣기
5. 저장 → 초록색 "연결됨"

> 쓰지 않는 결제수단은 [설정] → [결제 수단] 카드에서 끌 수 있어요. 바로 적용돼요.

## 3. 문자 · 알림톡 (Solapi)
1. solapi.com 가입 → 발신번호(고객센터 번호) 등록
2. API Key 생성 → API Key, API Secret 붙여넣기
3. 발신번호 숫자만 입력
4. (선택) 카카오 알림톡: 카카오 채널 연결 → pfId, 승인된 템플릿 ID를 알림 종류별로

**연결 테스트는 문자를 보내지 않고 잔액만 확인해요.**

## 4. 앱 푸시 (Firebase)
1. console.firebase.google.com 에서 프로젝트 생성 (앱 빌드 때도 같은 프로젝트 사용)
2. 프로젝트 설정 → 서비스 계정 → **새 비공개 키 생성** → .json 파일 다운로드
3. 파일을 메모장으로 열어 전체 복사 → 붙여넣기

## 5. 소셜 로그인
| 카드 | 붙여넣을 값 | 앱 빌드 담당에게 전달할 값 |
|---|---|---|
| 카카오 | 앱 ID (숫자) | 네이티브 앱 키 |
| 네이버 | Client ID | Client Secret |
| 구글 | 클라이언트 ID들 (쉼표로 구분) | iOS/Android 클라이언트 ID |
| 애플 | 번들 ID: `com.malkkeum.customer, com.malkkeum.partner` | – |

로그인 카드는 저장하면 "저장됨 · 앱에서 로그인해 확인하세요"가 나와요. 앱에서 실제로 로그인해 보면 확인돼요.

## 다 끝나면
맨 위 진행 막대가 가득 차고 "모든 준비가 끝났어요!"가 나와요. 이제 [3. 앱 출시](03-앱-출시.md)로 가세요.
