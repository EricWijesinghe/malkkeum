# 06. 알림톡 템플릿 등록 가이드 (사장님용)

고객에게 예약 확정, 기사 배정, 전날 알림, 청소 완료, 결제 영수증, 예약 취소를 **카카오 알림톡**으로 보내려면 아래 7개 템플릿을 카카오에 등록하고, 승인된 템플릿 ID를 설정 마법사의 **Solapi > templates** 항목에 넣어야 합니다.

- 알림톡은 **한국어 고객**에게만 나갑니다. 다른 언어를 쓰는 고객은 같은 내용을 **SMS**로 자기 언어로 받습니다. 따라서 템플릿은 한국어만 등록하면 됩니다.
- 템플릿이 없거나 알림톡 발송이 실패하면 같은 내용을 **SMS**로 자동 보냅니다. 템플릿을 아직 등록하지 않아도 고객은 안내를 받지만, SMS 요금이 알림톡보다 높습니다.
- 카카오 정책 변경: 친구톡(광고형 채널 메시지)은 2025년 12월 31일에 종료되었습니다. 이 가이드의 템플릿은 모두 **정보성 알림톡**이며, 광고 문구를 넣으면 심사에서 떨어집니다.

## 사전 준비 (카카오 비즈니스 계정 필요)

1. **카카오톡 채널** 개설 (사업자 등록 필요). 채널 관리자 센터에서 개설합니다.
2. **Solapi**에 로그인해 카카오톡 채널을 연동합니다. 연동하면 **pfId**(채널 ID)가 발급됩니다.
3. Solapi 콘솔 또는 카카오 채널 관리자 센터에서 템플릿을 등록합니다. 심사 기간은 카카오 정책에 따르며, 보통 영업일 기준으로 며칠이 걸립니다.
4. 승인되면 템플릿 ID를 복사합니다.

Solapi 문서: 알림톡 발송 https://solapi.com/developers/api/messages-ata , 발송 실패 시 SMS 대체 https://solapi.com/developers/api/messages-disablesms

## 공통 규칙

- 변수 두 개를 **반드시** 넣습니다: `#{title}`(제목)과 `#{body}`(내용). 서버는 이 두 변수만 보냅니다. 변수 이름은 띄어쓰기 없이 정확히 적습니다.
- 본문에 광고, 할인, 쿠폰, 이벤트 문구를 넣지 않습니다. 정보성 메시지만 가능합니다.
- 줄 바꿈은 Enter로 넣고, 본문은 1,000자 이내로 맞춥니다.
- 아래 7개는 같은 틀을 씁니다. 카카오 심사에서 템플릿마다 용도를 구분하도록 **템플릿 이름**만 다르게 붙이세요 (예: "예약 확정 안내").

## 공통 템플릿 본문 (7개 모두 동일하게 등록)

```
[말클큼] #{title}
#{body}
```

카테고리: **정보성** (예약/결제 안내). 버튼은 넣지 않아도 됩니다.

## 템플릿별 등록 내용

| 설정 키 (templates) | 용도 | 템플릿 이름 (예) | 서버에서 보내는 제목 / 내용 |
|---|---|---|---|
| `booking.confirmed` | 예약 확정 | 예약 확정 안내 | 제목: 예약이 확정됐어요 / 내용: 예약번호 |
| `partner.assigned` | 청소팀 배정 | 청소팀 배정 안내 | 제목: 청소팀이 배정됐어요 / 내용: 예약번호 |
| `booking.reminder` | 전날 알림 | 방문 전날 안내 | 제목: 내일 청소 예정이에요 / 내용: 예약번호 |
| `booking.arrival` | 기사 도착 | 기사 도착 안내 | 제목: 청소팀이 도착했어요 / 내용: 예약번호 (**현재 서버에서 아직 발송하지 않으므로 등록은 선택**) |
| `booking.completed` | 청소 완료, 후기 요청 | 청소 완료 안내 | 제목: 청소가 끝났어요 / 내용: 전후 사진을 확인해 보세요 |
| `payment.receipt` | 결제 영수증 | 결제 완료 안내 | 제목: 결제가 완료됐어요 / 내용: 영수증 안내 (**현재 서버에서 아직 발송하지 않으므로 등록은 선택**) |
| `booking.cancelled` | 예약 취소 | 예약 취소 안내 | 제목: 예약이 취소됐어요 / 내용: 예약번호 |

제목과 내용은 서버가 고객 언어가 아닌 한국어 원문으로 채웁니다. 템플릿 본문에는 고정 문구를 쓰지 않고 위 틀만 쓰면 심사 기준을 맞추기 쉽습니다.

## 설정 마법사에 입력하는 방법

설정 마법사 > **Solapi** 항목에서 다음을 입력합니다.

- `api_key`, `api_secret`: Solapi 콘솔 > 개발자 설정의 API 키
- `sender`: Solapi에 등록된 발신번호 (숫자만)
- `pf_id`: 카카오톡 채널 ID (Solapi에서 연동 후 발급된 값)
- `templates`: 위 표의 설정 키를 왼쪽, 승인된 템플릿 ID를 오른쪽에 넣은 JSON 객체

```json
{
  "booking.confirmed": "승인된_템플릿_ID_1",
  "partner.assigned": "승인된_템플릿_ID_2",
  "booking.reminder": "승인된_템플릿_ID_3",
  "booking.completed": "승인된_템플릿_ID_5",
  "booking.cancelled": "승인된_템플릿_ID_7"
}
```

위 예시에서 `booking.arrival`, `payment.receipt`는 서버가 아직 보내지 않으므로 생략해도 됩니다.

## 확인 방법

1. 설정 마법사에서 Solapi 항목의 **연결 확인**을 누릅니다 (잔액 조회만 하며 발송하지 않습니다).
2. 테스트 예약을 하나 만들고 확정, 배정, 취소 순서로 진행합니다. 실제 고객 번호가 아니라 테스트 계정 번호로 해 보세요.
3. 알림톡이 오지 않고 SMS가 왔다면 템플릿 ID, pfId, 변수 이름(`#{title}`, `#{body}`)을 다시 확인합니다.

## 자주 막히는 곳

- 템플릿 심사 반려: 광고 문구, 과도한 변수만 있는 본문, 변수 이름 오타가 원인인 경우가 많습니다.
- 변수 오류: 템플릿의 변수 이름이 `#{title}`, `#{body}`와 맞지 않으면 알림톡 발송이 실패하고 SMS로 대체됩니다.
- 발신번호 오류: 발신번호가 Solapi에 인증되지 않으면 SMS 대체 발송도 실패합니다.
- 비용: 알림톡 실패 후 SMS 대체 발송은 SMS 요금이 청구됩니다.
