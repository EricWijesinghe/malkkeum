# 3. 앱 출시 (App Store · Google Play)

맥(Mac)이 없어도 돼요. 앱은 **Codemagic**(클라우드 빌드 서비스)이 만들어서 스토어에 올려줘요.
아래 계정은 **사업자 명의**로 만들어야 해요 (스토어 정책).

## 준비물
| 계정 | 비용 | 소요 | 비고 |
|---|---|---|---|
| Apple Developer Program (조직) | 연 $99 | 1~7일 | D-U-N-S 번호 필요 (무료 발급, 며칠 걸림) |
| Google Play Console (**조직** 계정) | 1회 $25 | 1~3일 | 개인 계정은 출시 전 테스터 12명·14일 테스트가 의무라 조직 계정 권장 |
| Codemagic | 무료 플랜으로 시작 | 10분 | GitHub 계정으로 가입 |

## A. Apple 준비 (한 번만)
1. developer.apple.com → [Identifiers] 에서 App ID 두 개 만들기: `com.malkkeum.customer`, `com.malkkeum.partner`
   - 각각 **Sign in with Apple**, **Push Notifications** 체크
2. appstoreconnect.apple.com → [앱] → [+] 로 앱 두 개 등록 (이름: 말끔 / 말끔 파트너, 번들 ID는 위와 같게)
3. App Store Connect → [사용자 및 액세스] → [통합] → **App Store Connect API** 키 생성 (역할: App Manager) → `.p8` 파일 다운로드, Issuer ID·Key ID 메모

## B. Google 준비 (한 번만)
1. play.google.com/console → [앱 만들기] 두 번 (말끔 / 말끔 파트너)
2. [설정] → [API 액세스] 에서 서비스 계정 생성 → JSON 키 다운로드 → Play Console에서 이 계정에 **앱 출시 권한** 부여

## C. Codemagic 연결 (한 번만)
1. codemagic.io 에 GitHub로 로그인 → 저장소 추가
2. **Teams → Integrations → App Store Connect**: A-3의 키 등록, 이름을 `malkkeum_asc` 로
3. **Code signing → Android keystores**: [Generate keystore] 로 새로 만들거나 기존 파일 업로드, 참조 이름 `malkkeum_upload`
   - ⚠ 이 키스토어는 앱 업데이트에 계속 필요해요. 다운로드해서 .env 와 함께 안전하게 보관하세요.
4. **Environment variables** 에서 그룹 이름 `malkkeum` 으로 두 개 추가:
   - `API_BASE` = `https://도메인` (서버 주소)
   - `GCLOUD_SERVICE_ACCOUNT_CREDENTIALS` = B-2의 JSON 내용 (Secure 체크)

## D. 빌드하고 올리기 (업데이트할 때마다)
Codemagic 화면에서 **Start new build** → 워크플로 선택:
| 워크플로 | 결과 |
|---|---|
| `customer-ios` / `partner-ios` | TestFlight 에 업로드 → 아이폰 "TestFlight" 앱으로 바로 설치해 볼 수 있음 |
| `customer-android` / `partner-android` | Google Play **내부 테스트**에 업로드 |

## E. 심사 제출
스토어 정보 입력에 필요한 것:
- 앱 이름, 짧은 설명, 자세한 설명 → `docs/store/listing-ko.md` 에서 복사
- 스크린샷 → `docs/store/screenshots/` 폴더
- 개인정보처리방침 주소 → `https://도메인/privacy.html`
- 계정 삭제 안내 주소 (Google 필수) → `https://도메인/delete-account.html`
- 심사용 계정: 심사원은 한국 문자를 받을 수 없어요. 콘솔 [설정] → [스토어 심사용 데모 계정]에서 번호와 6자리 코드를 정해 켜고, 그 번호와 코드를 스토어의 **심사 메모(로그인 정보)** 칸에 적으세요. 14일 뒤 자동으로 꺼져요.
- Google Play **데이터 보안** 설문 → `docs/store/data-safety.md` 의 답을 그대로 선택

심사는 보통 Apple 1~3일, Google 1~7일 걸려요. 승인되면 [1. 설정 → 사업장 정보 → 앱 스토어 주소]에 스토어 주소를 넣어 웹사이트 버튼을 켜세요.
