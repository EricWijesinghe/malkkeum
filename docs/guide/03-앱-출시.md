# 3. 앱 출시 (App Store · Google Play)

앱은 **개발자가 만들어서 스토어에 올려요.** 설치 담당이 할 일은 스토어 계정을 만들고, 개발자를 팀원으로 초대하는 것뿐이에요.
맥(Mac)도, 코드도, 빌드 프로그램도 필요 없어요.

계정은 반드시 **사업자 명의**로 만들어요 (스토어 정책 — 앱 주인이 사장님이 되도록).

## 준비물
| 계정 | 비용 | 소요 | 비고 |
|---|---|---|---|
| Apple Developer Program (**조직**) | 연 $99 | 1~7일 | D-U-N-S 번호 필요 (무료 발급, 며칠 걸림) |
| Google Play Console (**조직**) | 1회 $25 | 1~3일 | 개인 계정은 출시 전 테스터 12명·14일 테스트가 의무라 조직 계정 권장 |

## A. Apple (한 번만)
1. developer.apple.com 에서 **조직**으로 가입 → 결제 → 승인 메일 기다리기
2. appstoreconnect.apple.com → [사용자 및 액세스] → [+] → 개발자 이메일 입력
   - 역할: **앱 관리(App Manager)**, "인증서·프로파일 접근" 체크
3. 같은 화면 [통합] → [App Store Connect API] → [+] → 이름 `malkkeum`, 역할 **앱 관리**
   - 내려받은 `.p8` 파일, **Issuer ID**, **Key ID** 를 개발자에게 전달 (아래 "전달 방법")

## B. Google (한 번만)
1. play.google.com/console 에서 **조직** 계정으로 가입 → $25 결제 → 신원 확인
2. [사용자 및 권한] → [새 사용자 초대] → 개발자 이메일
   - 권한: **앱 출시(테스트 트랙·프로덕션)**, **앱 정보 관리**
3. 앱은 개발자가 만들어요. 여기까지 하고 개발자에게 "초대 보냈어요" 라고 알려주면 끝

## 전달 방법
`.p8` 파일은 비밀번호와 같아요. 카카오톡 단체방·이메일 본문에 붙이지 말고, **개발자와 1:1로** 파일로만 보내세요.
보낸 뒤 개발자가 등록했다고 하면 내 PC의 파일은 지워도 돼요 (언제든 새로 만들 수 있음).

## B-2. 간편 로그인 · 알림 (선택)
카카오·네이버·구글 로그인과 앱 알림을 쓰려면, 개발자가 알려 주는 대로 각 개발자 사이트에 **사업자 명의**로 앱을 등록하고 개발자를 관리자로 초대해 주세요. 키 입력과 빌드는 개발자가 해요.

## C. 개발자가 해 주는 것
- 앱 두 개 등록 (말끔 / 말끔 파트너), 서버 주소(도메인)에 맞춰 빌드, 서명, 업로드
- 아이폰: **TestFlight** 로 먼저 보내 줘요 → 아이폰에서 "TestFlight" 앱을 받아 설치해 확인
- 안드로이드: Play **내부 테스트** 링크를 보내 줘요 → 휴대폰에서 링크를 열어 설치해 확인
- 확인이 끝나면 심사 제출

## D. 심사 때 사장님/설치 담당이 할 일
- **심사용 계정**: 심사원은 한국 문자를 받을 수 없어요. 콘솔 [설정] → [스토어 심사용 데모 계정]에서 번호와 6자리 코드를 정해 켜고, 그 번호와 코드를 개발자에게 알려 주세요. 14일 뒤 자동으로 꺼져요.
- 개인정보처리방침 주소: `https://도메인/privacy.html`, 계정 삭제 안내: `https://도메인/delete-account.html` (서버 설치 후 자동으로 생겨요)
- 스토어 설명 문구·데이터 보안 답변은 이 안내서 묶음의 `store/` 폴더에 있어요

심사는 보통 Apple 1~3일, Google 1~7일 걸려요. 승인되면 콘솔 [설정 → 사업장 정보 → 앱 스토어 주소]에 스토어 주소를 넣어 웹사이트 버튼을 켜세요.

## E. 스토어 사진 · 설명 문구 (개발자가 만들어요)
- 스토어 화면 사진은 `docs/store/screenshots/` 에 이미 만들어져 있어요 (고객·파트너 앱, 아이폰·아이패드·안드로이드 크기, 한국어·영어·일본어·중국어·베트남어).
- 화면이 바뀌면 개발자가 한 번에 다시 만들어요: `scripts/store/generate.sh`
- 설명 문구는 `docs/store/listing-*.md` 에 있고, 글자 수 제한은 `docs/store/check_listings.py` 로 확인해요.
- 개인정보 답변: Google 은 `docs/store/data-safety.md`, Apple 은 `docs/store/app-privacy.md`.
- 그 밖의 스토어 질문(광고, 대상 연령, 연령 등급, 금융 기능, 권한) 답변: Google 은 `docs/store/play-declarations.md`, Apple 은 `docs/store/app-privacy.md` 2·3항, 심사 메모는 `docs/store/review-notes.md`.

## 앱 업데이트
설치 담당은 할 일이 없어요. 개발자가 새 버전을 올리면 스토어가 휴대폰에 자동으로 업데이트해요.
