# 1. 서버 설치 (약 30분)

코드를 고칠 일은 없어요. 서버를 빌리고, 주소를 연결하고, 명령 한 줄을 붙여넣으면 끝나요.

## 준비물
| 준비물 | 어디서 | 비용(대략) |
|---|---|---|
| 도메인 (예: malkkeum.co.kr) | 가비아, 후이즈, Cloudflare 등 | 연 1~2만 원 |
| 서버 (Ubuntu 24.04, 메모리 2GB 이상, **서울 리전**) | AWS Lightsail, Vultr, 네이버 클라우드 등 | 월 1.5~3만 원 |

> 서버는 "Ubuntu 24.04 LTS", "서울(Seoul)" 지역, 메모리 2GB 이상을 고르세요. 디스크는 50GB면 충분해요.

## 순서

### ① 서버 만들기
1. 서버 회사 사이트에서 인스턴스(서버)를 만들어요. 운영체제는 **Ubuntu 24.04**를 고릅니다.
2. 만들어지면 화면에 나오는 **공인 IP 주소**(예: `3.38.12.34`)를 메모해요.
3. 방화벽(보안 그룹) 설정에서 **22, 80, 443** 포트를 열어요.

### ② 도메인 연결
1. 도메인을 산 사이트의 **DNS 관리** 화면으로 가요.
2. **A 레코드**를 추가해요. 호스트는 `@`(비워두기), 값은 ①의 IP 주소.
3. `www`로도 접속하게 하려면 `www` 호스트로 같은 A 레코드를 하나 더 만들어요.
4. 반영까지 몇 분 ~ 1시간 걸릴 수 있어요.

### ③ 설치 명령 실행
1. 서버 회사 화면의 **"브라우저에서 SSH 연결"**(또는 "콘솔 접속") 버튼을 눌러 검은 화면을 열어요.
2. 아래 한 줄을 붙여넣고 Enter (주소는 개발자가 알려준 것으로):
   ```
   curl -fsSL https://github.com/<계정>/<저장소>/releases/latest/download/install.sh | sudo bash
   ```
3. 질문 두 개에 답해요.
   - 서비스 주소 → `malkkeum.co.kr` (②에서 연결한 도메인)
   - 이메일 → 보안 인증서 안내를 받을 이메일
4. 몇 분 기다리면 이런 화면이 나와요:
   ```
   ✔ 설치가 끝났어요!
   1) 브라우저에서 이 주소를 여세요:   https://malkkeum.co.kr/admin/
   2) 설치 코드:  ABCD-2345-EFGH
   ```
5. **설치 코드를 메모**하세요. 사장님 계정을 만들 때 한 번 써요.

### ④ 중요한 파일 보관
서버의 `/opt/malkkeum/.env` 파일에 모든 보안 키가 들어 있어요. 이 파일이 없으면 백업을 되살릴 수 없어요.
- 검은 화면에서 `sudo cat /opt/malkkeum/.env` 를 입력하고, 나온 내용을 **비밀번호 관리자나 USB에 저장**하세요. 메신저나 이메일로 보내지 마세요.

### ⑤ 사장님 계정 만들기
1. `https://도메인/admin/` 을 열어요.
2. "환영합니다!" 화면에서 설치 코드, 이름, 이메일, 비밀번호(12자 이상)를 입력해요.
3. 로그인되면 왼쪽 메뉴 맨 아래 **[설정]** 으로 가서 [2. 설정 마법사](02-설정-마법사.md)를 따라 해요.

## 자주 쓰는 관리 명령 (검은 화면에서)
| 명령 | 하는 일 |
|---|---|
| `malkkeum status` | 서비스가 정상인지 확인 |
| `malkkeum update` | 최신 버전으로 업데이트 (자동 백업 후 진행) |
| `malkkeum backup` | 지금 바로 백업 |
| `malkkeum logs` | 오류 기록 보기 (Ctrl+C로 나가기) |
| `malkkeum setup-code` | 설치 코드 다시 보기 |
| `malkkeum restore backups/db-날짜.sql.gz` | 백업으로 되돌리기 |

자동으로 되는 것: **매일 새벽 3:30 백업**(14일 보관), **매주 월요일 새벽 4시 업데이트**, **HTTPS 인증서 자동 갱신**.

## 문제가 생기면
| 증상 | 해결 |
|---|---|
| 설치 끝에 "도메인이 이 서버를 가리키지 않아요" | ②의 A 레코드 확인. 고치고 몇 분 뒤 `malkkeum status` |
| 주소를 열면 "안전하지 않음" | DNS 반영 전이에요. 10~30분 뒤 다시 열기 |
| 설치 코드를 잃어버림 | `malkkeum setup-code` |
| 사이트가 안 열림 | `malkkeum status` → 안 되면 `malkkeum logs` 화면을 캡처해서 개발자에게 전달 |
