# 1. 서버 설치 (자세히)

처음이라면 [0. 한 번에 설치하기](00-한번에-설치.md) 한 장만 따라 하면 돼요. 이 문서는 같은 순서를 조금 더 자세히 설명하고, 체험용 데이터와 문제 해결을 다뤄요.

코드를 고칠 일도, 파일을 열어 고칠 일도 없어요. 서버를 빌리고, 주소를 연결하고, 명령 한 줄을 붙여넣으면 끝나요.

## 준비물
| 준비물 | 어디서 | 비용(대략) |
|---|---|---|
| 도메인 (예: `myshop.co.kr`) | 가비아, 카페24 같은 도메인 회사 | 연 1~2만 원 |
| 서버 (Ubuntu 24.04, **서울 리전**) | 가비아, 카페24, NHN 클라우드, AWS Lightsail 같은 서버 임대 회사 | 월 1.5~3만 원 |

> 서버는 "Ubuntu 24.04 LTS", "서울(Seoul)" 지역을 고르세요. 사양은 **권장 2 vCPU / 메모리 4 GB, 최소 메모리 2 GB** 예요. 디스크는 50 GB 면 충분해요 (설치에 최소 5 GB 의 빈 공간이 필요해요).
> 메모리 1 GB 서버도 설치는 돼요. 설치 프로그램이 스왑 2 GB 를 자동으로 만들지만 느릴 수 있어요.
> Ubuntu 22.04 와 Debian 12 에서도 설치돼요.

## 순서

### ① 서버 만들기
1. 서버 회사 사이트에서 인스턴스(서버)를 만들어요. 운영체제는 **Ubuntu 24.04**를 고릅니다.
2. 만들어지면 화면에 나오는 **공인 IP 주소**(예: `3.38.12.34`)를 메모해요.
3. 방화벽(보안 그룹) 설정에서 **22, 80, 443** 포트를 열어요.

### ② 도메인 연결
1. 도메인을 산 사이트의 **DNS 관리** 화면으로 가요.
2. **A 레코드**를 추가해요. 호스트는 `@`(비워두기), 값은 ①의 IP 주소.
3. `www`로도 접속하게 하려면 `www` 호스트로 같은 A 레코드를 하나 더 만들어요. (`www` 주소는 기본 주소로 자동 이동해요.)
4. 반영까지 몇 분 ~ 1시간 걸릴 수 있어요.

### ③ 설치 명령 실행
1. 서버 회사 화면의 **"브라우저에서 SSH 연결"**(또는 "콘솔 접속") 버튼을 눌러 검은 화면을 열어요.
2. 아래 한 줄을 그대로 붙여넣고 Enter:
   ```
   curl -fsSL https://raw.githubusercontent.com/EricWijesinghe/malkkeum-install/main/install.sh | sudo bash
   ```
3. 질문 두 개에 답해요. 잘못 입력하면 세 번까지 다시 물어봐요.
   - 서비스 주소 → `myshop.co.kr` (②에서 연결한 도메인)
   - 이메일 → 보안 인증서 안내를 받을 이메일 (없으면 Enter)
4. 설치 프로그램이 알아서 하는 일이에요.
   - 서버 점검 (메모리, 디스크, 80/443 포트)
   - 필요한 프로그램(Docker) 설치
   - 보안 키 만들기
   - 도메인이 이 서버를 가리키는지 확인
   - 서비스 시작, 매일 백업과 매주 업데이트 예약, `dahae` 관리 명령 설치
5. 도메인이 아직 연결되지 않았으면 넣어야 할 A 레코드 값을 보여 주고 기다려요. DNS 를 고친 뒤 **Enter** 를 누르면 다시 확인하고, `s` 를 입력하면 건너뛰어요.
6. 몇 분 기다리면 이런 화면이 나와요:
   ```
   ✔ 설치가 끝났어요!   (채널: stable)

   1) 브라우저에서 이 주소를 여세요:   https://myshop.co.kr/admin/
   2) 설치 코드를 입력하고 사장님 계정을 만드세요:

          설치 코드:  ABCD-2345-EFGH

   3) [설정] 메뉴에서 결제·문자·로그인 연동을 차례로 연결하세요.
   ```
7. **설치 코드를 메모**하세요. 사장님 계정을 만들 때 한 번 써요.

> "앱은 정상이에요. HTTPS 인증서는 아직이에요." 가 나오면 서비스는 켜졌고 도메인 연결만 남은 거예요. A 레코드가 반영되면 인증서가 자동으로 발급돼요. `sudo dahae status` 로 확인하세요.

### ④ 중요한 파일 보관
서버의 `/opt/malkkeum/.env` 파일에 모든 보안 키가 들어 있어요. 이 파일이 없으면 백업을 되살릴 수 없어요.
- 검은 화면에서 `sudo cat /opt/malkkeum/.env` 를 입력하고, 나온 내용을 **비밀번호 관리자나 USB에 저장**하세요. 메신저나 이메일로 보내지 마세요.
- 이 파일은 보관만 해요. 직접 고칠 일은 없어요. 바꿀 것이 있으면 `dahae` 명령이나 콘솔 [설정] 화면을 써요.

### ⑤ 사장님 계정 만들기
1. `https://도메인/admin/` 을 열어요.
2. "환영합니다!" 화면에서 설치 코드, 이름, 이메일, 비밀번호(12자 이상)를 입력해요.
3. 로그인하면 **2단계 인증 설정** 화면이 나와요. 휴대폰 인증 앱(Google Authenticator 등)에 키를 추가하고 6자리 코드를 입력해요.
4. 왼쪽 메뉴 **[설정]** 으로 가서 [2. 설정 마법사](02-설정-마법사.md)를 따라 해요.

### ⑥ 서버가 꺼지면 알림 받기 (권장)
서버는 자기가 꺼진 것을 스스로 알릴 수 없어요. healthchecks.io 같은 가동 확인 서비스에서 핑 주소를 받아 한 줄만 입력하세요.
```
sudo dahae heartbeat https://hc-ping.com/여기에-복사한-주소
```
자세한 순서는 [7. 운영 명령어](07-운영-명령어.md) 8번에 있어요.

## 자주 쓰는 관리 명령 (검은 화면에서)
명령마다 언제 쓰는지와 예시는 [7. 운영 명령어](07-운영-명령어.md)에 있어요.

| 명령 | 하는 일 |
|---|---|
| `sudo dahae status` | 서비스와 HTTPS 가 정상인지 확인 |
| `sudo dahae version` | 지금 쓰는 채널과 버전 확인 |
| `sudo dahae update` | 최신 버전으로 업데이트 (먼저 백업하고, 실패하면 자동으로 이전 버전으로 되돌려요) |
| `sudo dahae rollback` | 직전 버전으로 되돌리기 (업데이트 후 문제가 보일 때) |
| `sudo dahae channel beta` | 베타 채널로 바꾸기 (`stable` 로 되돌릴 수도 있어요) |
| `sudo dahae backup` | 지금 바로 백업 |
| `sudo dahae restore backups/db-날짜-시각.sql.gz` | 백업으로 되돌리기 (데이터와 사진 파일) |
| `sudo dahae logs` | 오류 기록 보기 (Ctrl+C로 나가기) |
| `sudo dahae setup-code` | 설치 코드 다시 보기 |
| `sudo dahae heartbeat 주소` | 서버가 꺼지면 알림 받기 |
| `sudo dahae demo load` | 체험용 손님·파트너·예약 데이터 넣기 |
| `sudo dahae demo clear` | 체험용 데이터만 지우기 |
| `sudo dahae uninstall` | 서비스 제거 (데이터는 남김. `--purge` 를 붙이면 데이터와 백업까지 삭제) |

예전 이름 `malkkeum` 으로 입력해도 같은 명령이 실행돼요.

## 체험용 데이터 넣기/지우기
화면이 비어 있으면 써 보기 어려울 때 쓰세요. 가짜 손님 40명, 파트너 12곳(팀원 포함), 최근 90일과 앞으로 14일의 예약, 결제, 채팅, 정산이 들어가요.

- **넣기:** `sudo dahae demo load`. 실제 예약이나 결제가 이미 있으면 넣지 않아요.
- **지우기:** `sudo dahae demo clear`. 체험용으로 넣은 데이터만 지우고, 실제 고객·예약·정산은 건드리지 않아요. 지우기 전에 한 번 더 물어봐요.
- 체험용 손님 전화번호는 `010-0000-xxxx` 같은 가짜 번호라 문자나 알림이 나가지 않아요. 결제도 실제로 청구되지 않아요.
- 체험용 상담사·관리자 계정은 아무도 로그인할 수 없는 임의 비밀번호로 만들어져요. `demo clear` 하면 계정도 함께 지워져요.
- 실제 서비스를 시작하기 전에는 반드시 `sudo dahae demo clear` 로 지우세요.

자동으로 되는 것: **매일 새벽 3:30 백업**(14일 보관), **매주 월요일 새벽 4시 업데이트**(실패하면 자동 복구), **HTTPS 인증서 자동 갱신**.
설치 명령을 다시 실행해도 안전해요. 설정과 데이터는 그대로 두고, 백업한 뒤 업데이트해요.
베타 채널 서버는 위 설치 주소의 `main` 을 `beta` 로 바꾼 주소로 설치해요. 사장님께 드린 설치 안내는 `stable` 이에요.
배포 저장소에 들어 있는 안내서의 설치 주소는 버전 태그(`…/v1.2.3/install.sh`)로 고정돼 있어요. 태그는 바뀌지 않고, 같은 태그의 `SHA256SUMS` 로 파일을 확인할 수 있어요 (`sha256sum -c SHA256SUMS`).

## 문제가 생기면
| 증상 | 해결 |
|---|---|
| 설치 중 "도메인이 아직 이 서버를 가리키지 않아요" | ②의 A 레코드를 화면에 나온 값으로 고치고 Enter. 건너뛰었다면 몇 분 뒤 `sudo dahae status` |
| "80/443 포트를 다른 프로그램이 쓰고 있어요" | 서버에 다른 웹 서버가 있어요. `sudo systemctl disable --now nginx apache2` 후 설치 명령 다시 실행 |
| 주소를 열면 "안전하지 않음" | DNS 반영 전이에요. 10~30분 뒤 다시 열기 |
| 설치 코드를 잃어버림 | `sudo dahae setup-code` |
| 사이트가 안 열림 | `sudo dahae status` → 안 되면 `sudo dahae logs` 화면을 캡처해서 개발자에게 전달 |
| 업데이트 후 문제가 생김 | `sudo dahae rollback` 으로 직전 버전의 프로그램으로 되돌리기. 고객·예약 데이터는 지워지지 않아요. 데이터까지 예전 시점으로 돌리려면 `sudo dahae restore` ([7. 운영 명령어](07-운영-명령어.md) 4번) |
