# 다해 안내서

처음이라면 **0번 한 장**만 따라 하면 설치가 끝나요.

| 번호 | 안내서 | 누가 | 언제 |
|---|---|---|---|
| 0 | [한 번에 설치하기](00-한번에-설치.md) | 사장님 또는 설치 담당 | 처음 한 번 (약 30분) |
| 1 | [서버 설치 (자세히)](01-서버-설치.md) | 설치 담당 | 0번에서 막혔을 때, 체험용 데이터 |
| 2 | [설정 마법사](02-설정-마법사.md) | 설치 담당 + 사장님 | 설치 직후 (결제·문자·로그인 연결) |
| 3 | [앱 출시](03-앱-출시.md) | 설치 담당 → 개발자 | 스토어에 앱을 올릴 때 |
| 4 | [사장님 가이드](04-사장님-가이드.md) | 사장님 | 매일 5분 |
| 5 | [체험용 설치](05-demo-install.md) | 개발자 | 인터넷 없이 시연할 때 |
| 6 | [알림톡 템플릿 등록](06-알림톡-템플릿-등록.md) | 설치 담당 | 카카오 알림톡을 쓸 때 |
| 7 | [운영 명령어](07-운영-명령어.md) | 설치 담당 | 백업, 업데이트, 문제 확인 |

## 급할 때
| 상황 | 볼 곳 |
|---|---|
| 사이트가 안 열려요 | [7. 운영 명령어](07-운영-명령어.md) 1번 `status`, 2번 `logs` |
| 업데이트 뒤에 이상해요 | [7. 운영 명령어](07-운영-명령어.md) 6번 `rollback` |
| 데이터를 되살려야 해요 | [7. 운영 명령어](07-운영-명령어.md) 4번 `restore` |
| 설치 코드를 잃어버렸어요 | 서버에서 `sudo dahae setup-code` |
