# Google Play 데이터 보안 · App Store 개인정보 라벨 답안

근거: `website/privacy.html` 과 실제 코드(백엔드 `migrations/`, `routes/`). 정책이 바뀌면 둘 다 고치세요.

## 공통 질문
| 질문 | 답 |
|---|---|
| 사용자 데이터를 수집하거나 공유하나요? | 예 |
| 전송 중 데이터는 암호화되나요? | 예 (HTTPS 전용) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 예 — 앱 내 회원 탈퇴, 웹: `https://도메인/delete-account.html` |

## 수집 항목 (고객 앱)
| Google 분류 | 항목 | 수집 | 공유 | 필수? | 목적 |
|---|---|---|---|---|---|
| 개인 정보 | 이름 | 예 | 예 (배정된 청소 파트너, 일부 가림) | 선택 | 앱 기능, 계정 관리 |
| 개인 정보 | 이메일 주소 | 예 (소셜 로그인 시) | 아니요 | 선택 | 계정 관리 |
| 개인 정보 | 전화번호 | 예 | 아니요 | 필수 | 계정 관리, 앱 기능(알림) |
| 개인 정보 | 주소 | 예 | 예 (배정된 파트너) | 필수 | 앱 기능 |
| 금융 정보 | 구매 내역 | 예 | 아니요 | 필수 | 앱 기능 |
| 사진 및 동영상 | 사진 | 예 (사용자가 올린 경우) | 예 (배정된 파트너) | 선택 | 앱 기능 |
| 메시지 | 앱 내 메시지 | 예 | 아니요 | 선택 | 고객 지원 |
| 기기 또는 기타 ID | 푸시 토큰 | 예 | 아니요 | 선택 | 앱 기능(알림) |

- 결제 카드 정보: 앱/서버가 수집하지 **않음** (결제대행사가 처리) → "금융 정보 > 결제 정보"는 **아니요**
- 위치(GPS): 수집하지 **않음** (사용자가 입력한 주소만)
- 광고 ID, 분석 SDK: 사용하지 **않음** → 광고·마케팅·분석 목적은 모두 **아니요**

## 파트너 앱 추가 항목
| 분류 | 항목 | 목적 |
|---|---|---|
| 금융 정보 | 기타 금융 정보 (정산 계좌, 암호화 저장) | 앱 기능 (정산) |

## App Store 개인정보 라벨
- **사용자에게 연결된 데이터**: 연락처 정보(이름, 이메일, 전화번호, 실제 주소), 사용자 콘텐츠(사진, 고객 지원 메시지), 구입 항목, 식별자(사용자 ID)
- **추적에 사용되는 데이터**: 없음
- 목적: 앱 기능, 고객 지원 (제3자 광고·분석 없음)
