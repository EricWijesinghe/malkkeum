# Ideas beyond the contract (for the owner to choose)

The contracted scope is built. These are optional upgrades, roughly ordered by value per effort. None are in the code yet.

1. **Smart rebooking reminders**: "It's been 3 months since your aircon clean" pushes, with one tap to rebook the same options. Drives repeat revenue.
2. **Live "team on the way" status**: the pro taps "departed" / "arrived" and the customer sees it on the booking timeline. Very few Korean competitors offer this.
3. **Before/after gallery on service pages**: real completion photos (with customer consent) as social proof.
4. **Home profile**: saved notes per address (pets, door code, parking) reused on every booking.
5. **Cross-sell coupon claim screen**: the spec's air-conditioner coupon offered during move-in booking. The backend coupon engine supports it; it needs a campaign endpoint and UI.
6. **KakaoTalk AlimTalk**: booking confirmations in KakaoTalk, which Korean customers read more than push notifications.
7. **Team-member logins**: members currently get SMS. A member login would show only their assigned jobs.
8. **Analytics**: conversion funnel per booking step, repeat rate, and partner acceptance time in the console dashboard.
