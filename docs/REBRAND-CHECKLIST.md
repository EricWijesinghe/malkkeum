# 다해(Dahae) 이름 변경 — 사장님 확인 목록

앱·콘솔·웹사이트·스토어 문구의 이름을 "말끔"에서 **"다해 / Dahae"** 로 바꿨어요.
코드로 바꿀 수 있는 것은 끝났고, 아래는 **사장님이 직접 확인하거나 외부 사이트에서 처리해야 하는 일**이에요.
"스토어 제출 전 필수" 표시가 있는 항목은 끝내기 전에 앱을 올리지 마세요.

## 1. 법적 확인 (스토어 제출 전 필수)

- [ ] **상표 검색**: KIPRIS(https://www.kipris.or.kr)에서 "다해"를 37류(청소업), 35류(중개·광고), 9류(앱)로 검색하세요.
      "다해"는 흔한 단어라 이미 등록된 상표가 있을 가능성이 높아요. 겹치면 변리사와 상의한 뒤 이름을 확정하세요.
- [ ] **상호와 서비스 이름 구분**: "다해"가 사업자등록증의 상호인지, 서비스 이름일 뿐인지 정하세요.
      이용약관 제1조와 사업자 정보(웹사이트 바닥글, 앱의 사업자 정보 화면)는 콘솔 [설정 > 사업자 정보]의 **상호(legal_name)** 를 그대로 보여 줘요.
      상호를 바꾸지 않았다면 그 칸은 사업자등록증 이름 그대로 두세요.
- [ ] **약관 변경 공지 (시행 7일 전)**: 이름만 바뀌어도 이용약관·개인정보처리방침 문구가 바뀐 것이에요.
      시행일 최소 7일 전에 앱 공지사항과 웹사이트에 변경 공지를 올리세요.
      현재 문서의 시행일은 `scripts/build_legal.py` 의 `EFFECTIVE`(2026년 11월 17일)예요. 공지일 + 7일 이후로 고친 뒤 다시 생성하세요
      (`python -I scripts/build_legal.py website`).
- [ ] **약관 문구 검토**: 이번에 바뀐 문구(아래 4번)를 한 번 읽어 보세요. 특히 제5조 취소·환불 문구는 법률 검토를 권해요.

## 2. 외부 서비스에 보이는 이름 (각 사이트에서 직접 변경)

- [ ] **카카오톡 채널**: 채널 프로필 이름 변경은 카카오 심사가 필요해요. 심사가 끝날 때까지 알림톡은 예전 채널 이름으로 나가요.
- [ ] **알림톡 템플릿**: 템플릿은 `#{brand}` 변수를 써서 본문은 자동으로 "다해"가 돼요. 다만 승인은 템플릿 문구 단위라서,
      템플릿에 "말끔"을 직접 적어 둔 것이 있으면 새로 등록해 승인받아야 해요 (`docs/guide/06-알림톡-템플릿-등록.md`).
- [ ] **결제대행(PG) 가맹점 표시 이름**: PortOne, 카카오페이, 네이버페이, 토스페이 관리자 화면의 가맹점 이름과 카드 명세서 표시 이름을 바꾸세요.
      바꾸지 않으면 고객 카드 명세서에 예전 이름이 찍혀요.
- [ ] **소셜 로그인 동의 화면**: 카카오·네이버·Apple·Google 개발자 콘솔의 앱 이름을 "다해"로 바꾸세요.
- [ ] **문자 발신 프로필**: 운영 알림 문자는 이제 `[다해]`(콘솔에 저장한 사업자 이름)로 시작해요. 발신번호 사전등록 내용은 그대로예요.

## 3. 사장님이 정해야 하는 것

- [ ] **앱 ID와 도메인 (첫 스토어 업로드 전 필수)**: 앱 ID `com.malkkeum.*`, 도메인, 네이버 로그인 주소(`malkkeumnaver`),
      Windows 패키지 게시자(`CN=Malkkeum Test`)는 **바꾸지 않았어요**. 스토어에 한 번 올리면 앱 ID는 바꿀 수 없으니, 올리기 전에 유지할지 정하세요.
- [ ] **이미 저장된 사업자 이름·색상**: 콘솔에서 저장한 값이 기본값보다 우선해요. 운영 서버에 "말끔"이나 예전 색(#3B5BFD)이 저장돼 있으면
      콘솔 [설정 > 사업자 정보]에서 이름을 "다해", 색을 `#187A8F`로 다시 저장하세요. (자동으로 바꾸지 않았어요.)
- [ ] **호스팅 제공자**: 콘솔 [설정 > 사업자 정보]의 "호스팅 제공자" 칸을 채우세요. 웹사이트 바닥글, 이용약관, 검색용 페이지에 표시돼요 (전자상거래법).
- [ ] **사업자정보확인 링크**: 사업자등록번호 10자리를 저장하면 웹사이트 바닥글과 이용약관에 공정거래위원회 조회 링크가 자동으로 나와요.
      실제 번호를 저장한 뒤 링크를 눌러 내 사업자 정보가 뜨는지 확인하세요.
- [ ] **스토어 스크린샷**: 예전 이름과 색이 들어간 스크린샷은 다시 만들어야 해요 (`docs/store/screenshots`).
- [ ] **체험판(데모) 키트**: 새로 불러온 예시 데이터에는 가짜 사업자 정보("(예시) 다해 주식회사", 000-00-00000)가 들어가요.
      이미 예시 데이터가 들어 있는 키트는 `demo clear` 후 `demo load` 를 다시 해야 보여요.
- [ ] **직원 2단계 인증 앱**: 새로 등록하는 직원은 인증 앱에 "Dahae staff"로 표시돼요. 이미 등록한 직원은 예전 이름으로 보이지만 그대로 쓸 수 있어요.

## 4. 이번에 바뀐 약관·방침 문구

`scripts/build_legal.py` 로 다시 생성해서 생성기와 웹 페이지가 같아졌어요. 앞으로 `.html` 을 직접 고치지 마세요
(`python -I scripts/build_legal.py website --check` 로 차이를 확인할 수 있어요).

| 문서 | 바뀐 내용 |
|---|---|
| 전체 5개 (개인정보처리방침, 이용약관, 위치기반서비스 이용약관, 계정 삭제 안내, 파트너 지원) | 서비스 이름 "말끔" → "다해". 바닥글에 "사업자정보확인" 링크 추가. 브라우저 제목 순서를 "다해 · 문서 이름"으로 변경 |
| 개인정보처리방침 1항 "자동 수집" | "오류 보고(앱 버전·오류 내용, 전화번호·이메일 제거 후 14일 보관)" 추가. 생성기에는 이미 있었고 웹 페이지에만 빠져 있었어요 |
| 이용약관 제5조 (취소와 환불) | 예전 웹 페이지: "방문일 2일 전까지 취소: 전액 환불 / 그 이후 취소: 앱에 안내된 취소 수수료 기준에 따름". 지금: 서버 기본 취소 규정 그대로 "방문일 2일 전까지 취소: 전액 환불 / 방문일 1일 전까지 취소: 앱에서 취소 불가, 상담팀 확인 후 처리 / 방문 당일 취소: 앱에서 취소 불가, 상담팀 확인 후 처리" |
| 이용약관 "사업자 정보" | 호스팅 제공자, 고객센터 전화·이메일, 사업자정보확인 링크 추가 |
| 파트너 지원 | 그림 아이콘만 변경 (문구 그대로) |

주의: 콘솔에서 취소 규정을 바꾸면 이용약관 제5조에는 자동으로 반영되지 않아요. 규정을 바꾼 뒤에는 약관도 다시 생성해 주세요.
