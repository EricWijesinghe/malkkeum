다해 서버 설치 파일 만들기

서버를 빌린 뒤, 이 페이지에서 만든 내용을 서버 만들기 화면에 붙여넣으면 설치가 자동으로 시작돼요.

1. 준비할 것

  1. 서버 호스팅 업체에서 Ubuntu 24.04 서버를 하나 만드세요.
  2. 쓰실 도메인(예: myshop.co.kr)을 준비하세요. 도메인의 A 기록을 서버 주소로 바꿀 때까지 몇 분에서 한 시간이 걸릴 수 있어요.
  3. 알림을 받을 이메일 주소를 준비하세요.

2. 정보 입력

이 내용에는 설치 인증 코드가 들어 있어요. 2시간 안에 서버를 만들고, 다 쓰고 나면 이 화면과 복사한 내용을 지워 주세요.

3. 서버 만들기 화면에 붙여넣기

호스팅 업체의 "사용자 데이터(User data)" 또는 "cloud-init" 칸에 아래 내용을 그대로 붙여넣으세요.

4. 다음 단계

  1. 서버가 켜지면 10~20분 정도 기다리세요. 설치가 끝나면 설치 인증 코드가 화면에 나와요.
  2. 다해 서버 도우미 앱 또는 관리 콘솔에서 그 코드를 입력하세요.
